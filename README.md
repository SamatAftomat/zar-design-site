# Завод Архитектурных Решений — сайт

Одностраничный сайт для **Завода Архитектурных Решений** — дизайн-бюро в Нижнекамске
(Корабельная улица, 45а, 2 этаж, 35-й м-н).

- Данные: карточка [2ГИС](https://2gis.ru/nizhnekamsk/firm/70000001104619353) —
  3,9 ★, 6 оценок, 29 фото, цены (9 позиций), контакты, рубрики, оплата
- Статический сайт: HTML + CSS + JS, без сборки
- Стиль: «Сигнальный чертёж» (Unbounded + Manrope) — как у сайтов 01/02/03/04

## Особенности этой карточки

- Прайс открыт: 9 позиций материалов (обои Loymina, ламинат Joss Beaumont,
  штукатурки Decoro/Короед, фрески Ortograf, паркет FINEX, краска Silk Plaster,
  микроцемент) — все вынесены в блок «Материалы и цены», указано «не оферта»,
  обновлено 11.03.2026
- Фото работ: 3 рендера из галереи 2ГИС (санузел, спальня, гостиная)
- Отзывы взяты через публичный API отзывов 2ГИС; на сайт вынесены 4 отзыва 5★
  (Ирина Л, Эльмира Г, Кристина В, Алексей А). Один отзыв на 1 звезду
  («Разочарование…») — на сайт не вынесен; общий рейтинг карточки 3,9 —
  показан честно
- Рубрики карточки: дизайн интерьеров, ландшафтный дизайн, ремонт помещений,
  мебель на заказ + продажа материалов
- Часы: пн–пт 09:00–18:00, сб–вс выходной; оплата — через банк
- Телефон в карточке один: +7 917 850-16-76. Второй номер на страницах
  карточки появляется из рекламных блоков — на сайт не вынесен
- Сайт компании, WhatsApp и соцсети в карточке не опубликованы — мессенджер-кнопки
  не используются, только звонок и ссылка на карточку 2ГИС
- Ориентир «Лагуна» (транспорт, 400 м) — из вкладки «Инфо»

## Локальный запуск

и открыть http://localhost:8000
